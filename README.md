# Saini Public School Website

A complete, premium website for **Saini Public School**, an educational institution offering education from **Foundation Stage through Class 8**.

## Official Tagline
> **“Every student has its own qualities like flowers.”**

## Brand Color Palette
- **Forest Green**: `#234B38` (Primary brand color)
- **Warm Beige**: `#D7BBA8` (Secondary accent)
- **Warm Ivory**: `#F8F6F0` (Background)
- **Charcoal Green**: `#29342D` (Text typography)
- **White**: `#FFFFFF` (Clean content surfaces)

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features
- **Official Brand Crest**: Bespoke SVG botanical seal symbolizing individuality and academic excellence.
- **Hero Section**: Exact school name, preserved tagline, supporting statement, and admissions CTAs.
- **Our Educational Journey**: Three connected stages (Foundation Stage, Primary Education, Middle School).
- **About Us**: Comprehensive tabs for About Our School, Our Vision, Our Mission, Our Approach, and 6 Core Values.
- **Learning & Student Development**: 6 core developmental pillars.
- **Campus & Facilities**: Interactive spotlight covering classrooms, library, labs, sports, and safety.
- **Interactive Admissions**: Enquiry form with client validation, reference code generator, eligibility table, and document checklist.
- **School Notices**: Searchable noticeboard with category filtering and circular reader modal.
- **Gallery**: Photo gallery with category filters and full-screen lightbox.
- **Contact & Tours**: Address, office hours (Mon–Sat 8:00 AM – 3:00 PM), campus walk scheduler, and FAQs.
